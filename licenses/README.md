# Additional runtime license texts

These license texts accompany the browser assets prepared by `scripts/prepare-assets.mjs`.

- `LPPL-1.3c.txt`: verbatim [LaTeX Project Public License 1.3c](https://www.latex-project.org/lppl/lppl-1-3c.txt), fetched 2026-11-06. Applies to the unmodified `florilegium-pgfmath.lua` file; its original attribution and maintenance header is also preserved.
- `Lua-MIT.txt`: copyright notice from the [Lua 5.4.6 public header](https://github.com/lua/lua/blob/v5.4.6/lua.h), with C comment delimiters removed, fetched 2026-11-06. Lua is the interpreter compiled into Wasmoon's WebAssembly runtime.

Florilegium's MIT license and font OFL notices are copied from the pinned submodule. Wasmoon's MIT license and the other runtime npm dependency licenses are copied from their locked packages during preparation. See `THIRD_PARTY_NOTICES.md` at the repository root and in the built site.
